# Créditos

O Versão Brasileira é distribuído sob a licença GPL-3.0 (arquivo LICENSE).

Partes do código foram reaproveitadas, com adaptações, destes projetos (ambos GPL-3.0):

- **3dsDL** — ankushKun — https://github.com/ankushKun/3dsDL
  Kit de interface (`source/ui/ui.*`, atlas de ícones, `scripts/make-ui-icons.py`),
  rede (`source/download/`), utilitários de arquivos, registro e plataforma
  (`source/storage/`, `source/platform/`), leitor de JSON (`source/repository/json.*`).
- **Universal Updater** — Universal-Team — https://github.com/Universal-Team/Universal-Updater
  Referência para o formato das etapas de instalação (downloadFile, extractFile,
  copyFile, deleteFile, installCia).

Bibliotecas de terceiros: stb_image (domínio público / MIT), libctru, citro2d,
citro3d, libcurl, Mbed TLS, libarchive e bibliotecas de compressão do devkitPro.

Ferramentas incluídas em `tools/` só para gerar o `.cia` (ver `tools/LICENCAS.md`):

- **makerom** — Project_CTR (3DSGuy, applestash, jakcron) — https://github.com/3DSGuy/Project_CTR — MIT.
- **bannertool** — Steveice10 — https://github.com/Steveice10/bannertool.
